## 2. Feature Cards (Core & SDK Slices)

### Hybrid Module Loader, Settings, Lockfiles, CLI & Resilience (`Foundation.Core.dll v0.3.0`)
- **What it does:** Provides the shared .NET 8 infrastructure primitives across all Sister Apps: `IFoundationModule` & `HybridModuleLoader`, `GranularSettingsManager` (3-file split + 20-snapshot `config_history\` + `.bak` recovery), `DpapiSecretStore` (`data\secrets.dpapi`), `SqliteWalPool` (`64 MB` page cache + `SqliteCacheMode.Default`), `PidSafeLockfile`, `SafeNetworkTransfer` (6-pillar safety), `SandboxEnvironment`, `CrashBundleService`, `HeartbeatLogger`, `ToolResolver`, `JobObjectGuard`, `CliSchema`, `BoundedTailStream`, and `CappedSharedLogSink`.
- **Entry Points:** [`IFoundationModule.cs`](file:///<PROJECTS_ROOT>/Foundation/Dev/src/Foundation.Core/IFoundationModule.cs), [`GranularSettingsManager.cs`](file:///<PROJECTS_ROOT>/Foundation/Dev/src/Foundation.Core/GranularSettingsManager.cs), [`SqliteWalPool.cs`](file:///<PROJECTS_ROOT>/Foundation/Dev/src/Foundation.Core/SqliteWalPool.cs), [`PidSafeLockfile.cs`](file:///<PROJECTS_ROOT>/Foundation/Dev/src/Foundation.Core/PidSafeLockfile.cs), [`CliAndProcessPrimitives.cs`](file:///<PROJECTS_ROOT>/Foundation/Dev/src/Foundation.Core/CliAndProcessPrimitives.cs)

### Retro Platform Catalog, Multi-DAT Parser, Copier Header Stripper & Soft-Patcher (`Foundation.Retro.dll v0.1.0`)
- **What it does:** Centralizes the 64-platform retro system catalog (`ConsoleSystemCatalog`), 50+ authoritative BIOS MD5/SHA-1/Size definitions, copier header-skip rules (`ines-16`, `fwnes-16`, `smc-512`, `a7800-128`, `lynx-64`), provenance tag tiers (`[PR]`, `[Lic]`, `[PRt]`), 1G1R title key normalizer (`DatTitleNormalizer`), streaming XML/ClrMamePro/SFV/MD5 DAT parser (`NoIntroRedumpDatParser`), magic-byte platform detector (`HeaderlessRomStripper` / `MagicBytePlatformDetector`), and pure in-memory `IPS`/`BPS1`/`UPS1` binary ROM soft-patchers (`SoftPatchEngine`).
- **Entry Points:** [`ConsoleSystemCatalog.cs`](file:///<PROJECTS_ROOT>/Foundation/Dev/src/Foundation.Retro/ConsoleSystemCatalog.cs), [`NoIntroRedumpDatParser.cs`](file:///<PROJECTS_ROOT>/Foundation/Dev/src/Foundation.Retro/NoIntroRedumpDatParser.cs), [`DatTitleNormalizer.cs`](file:///<PROJECTS_ROOT>/Foundation/Dev/src/Foundation.Retro/DatTitleNormalizer.cs), [`HeaderlessRomStripper.cs`](file:///<PROJECTS_ROOT>/Foundation/Dev/src/Foundation.Retro/HeaderlessRomStripper.cs), [`SoftPatchEngine.cs`](file:///<PROJECTS_ROOT>/Foundation/Dev/src/Foundation.Retro/SoftPatchEngine.cs)
- **Verification Tests:** [`FoundationDecouplingTests.cs`](file:///<PROJECTS_ROOT>/Foundation/Dev/tests/Foundation.Tests/FoundationDecouplingTests.cs)
- **Extension Point / What to Touch:** `[Extension Point -> Dev/docs/ARCHITECTURE.md]`: Add new retro platform definitions or DAT format parsers in `Dev\src\Foundation.Retro\`.
